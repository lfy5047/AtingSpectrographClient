# 温控仪通信协议

## 1. 通讯语法概述

通讯命令分为三类：**设定命令**、**查询命令**、**保存命令**。

---

## 2. 设定命令

设定命令用于设定某个参数的值。

### 2.1 语法

```
MODULENAME:PARAMNAME=PARAMVALUE\r
```

整条命令由四部分组成：**模块参数名**、**等号**、**设置值**、**结束符** `\r`。

| 片段 | 含义 |
|------|------|
| `MODULENAME` | 子模块名称 |
| `PARAMNAME` | 参数名称 |
| `PARAMVALUE` | 要设置的值 |

### 2.2 示例

```
TC1:TCADJUSTTEMP=25\r
```

含义：将子模块 `TC1` 的参数 `TCADJUSTTEMP`（温度控制器的调节温度）设为 `25`。

### 2.3 说明与应答

- 并非每个参数都可被设置；部分参数仅支持查询，部分不对外公开。
- 下位机执行后返回格式：

```
CMD:REPLY=ERRORCODE\r
```

其中 `ERRORCODE` 为错误信息码。

---

## 3. 查询命令

查询命令用于读取某个参数的当前值。

### 3.1 语法

```
MODULENAME:PARAMNAME?\r
```

由三部分组成：**模块参数名**、**问号 `?`**、**结束符** `\r`。

### 3.2 示例

```
TC1:TCADJUSTTEMP?\r
```

含义：查询子模块 `TC1` 中参数 `TCADJUSTTEMP` 的值。

### 3.3 说明与应答

- 绝大部分参数都可以被查询。
- **查询成功**时，返回格式与设定命令一致：

```
MODULENAME:PARAMNAME=PARAMVALUE\r
```

示例：

- 发送：`TC1:TCADJUSTTEMP?\r`
- 返回：`TC1:TCADJUSTTEMP=25\r`

- **查询失败**时，返回：

```
CMD:REPLY=ERRORCODE\r
```

其中 `ERRORCODE` 为错误信息码。

---

## 4. 保存命令

保存命令用于将某个参数的当前设定值写入非易失存储，以便下次上电仍使用该值。

### 4.1 语法

```
MODULENAME:PARAMNAME!\r
```

由三部分组成：**模块参数名**、**叹号 `!`**、**结束符** `\r`。

### 4.2 示例

```
TC1:TCADJUSTTEMP!\r
```

含义：保存子模块 `TC1` 中参数 `TCADJUSTTEMP` 的当前设定值；下次开机读取保存值。

### 4.3 说明与应答

- 只有「可设定」的参数才可能保存；但并非所有可设定参数都支持保存。
- 下位机执行后返回：

```
CMD:REPLY=ERRORCODE\r
```

其中 `ERRORCODE` 为错误信息码。

---

## 5. 语法说明（字段释义）

### 5.1 `MODULENAME`（子模块名称）

由下位机定义。常见举例：

| 名称 | 含义 |
|------|------|
| `TC1` | 温度控制器 — 温度控制子模块 1 |
| `TC2` | 温度控制器 — 温度控制子模块 2 |
| `LD1`、`LD2` | 恒流驱动器中的子模块 |
| `PCB` | 电路板温度监视子模块 |
| `MEMORY` | 存储器子模块 |

### 5.2 `PARAMNAME`（参数名称）

由下位机定义。与子模块名之间用 **冒号 `:`** 分隔，形如：`模块名:参数名`。

### 5.3 命令类型符号

| 符号 | 含义 |
|------|------|
| `=` | 标明 **设定命令** |
| `?` | 标明 **查询命令** |
| `!` | 标明 **保存命令** |

### 5.4 结束符 `\r`

表示一条命令结束的 **回车符**，占 **1 字节**，ASCII 为 **`0x0D`**。在 C 语言字符串里常写作 `"\r"`（转义写法）。

### 5.5 `ERRORCODE`（错误信息码）

下位机执行命令后通过该码反馈 **执行结果**（含成功与各类失败），便于上位机判断命令是否成功及失败原因。

## 6. 通讯规则

### 6.1 大小写敏感

所有通讯命令 **区分大小写**。通常情况下，下位机命令均为 **大写**。

### 6.2 必须以 `\r` 结尾

无论上位机 → 下位机，还是下位机 → 上位机，每条命令末尾都必须带 `\r`，即整条字符串最后一个字节为 **`0x0D`**。缺少结束符视为非法命令，不予识别。

### 6.3 ASCII 传输与查询示例

命令均以 **ASCII 字符串** 形式定义并在串口按各字符的 ASCII 字节依次发送。

**示例：** 查询温控调节温度

```
TC1:TCADJUSTTEMP?\r
```

在 C 语言中为 `"TC1:TCADJUSTTEMP?\r"`，串口依次发送：

`0x54, 0x43, 0x31, 0x3A, 0x54, 0x43, 0x41, 0x44, 0x4A, 0x55, 0x53, 0x54, 0x54, 0x45, 0x4D, 0x50, 0x3F, 0x0D`

文中 **`0xHH`** 表示该字节 ASCII 码的十六进制值。例如：`T`=0x54，`C`=0x43，`?`=0x3F，结束符 `\r`=**0x0D**。

### 6.4 数值亦为 ASCII 字节（设定示例）

设定命令中的数字及下位机返回的数值，同样按 **各数字字符的 ASCII** 发送。

**示例：** 将温度设为 25.01 ℃

```
TC1:TCADJUSTTEMP=25.01\r
```

C 语言字符串：`"TC1:TCADJUSTTEMP=25.01\r"`，共 **23 字节**，末尾依次为：

`… 0x3D (=), 0x32 ('2'), 0x35 ('5'), 0x2E (.), 0x30 ('0'), 0x31 ('1'), 0x0D (\r)`

### 6.5 禁止多余空格

命令 **中间及前方** 不得插入空格。

### 6.6 发送间隔 ≥ 50 ms

相邻两条 **发往下位机** 的命令，间隔须 **大于 50 ms**；过短可能被忽略。可在下发设定命令后等待 50 ms，再发查询命令确认是否生效。

### 6.7 地址码（可选）

在命令后紧跟 **`@X`**，`X` 为目标下位机串口地址。**单机** 时可不用。

### 6.8 校验码（可选）

在地址码（若有）之后可跟 **`#YY`**，`YY` 为 **异或校验和**。

### 6.9 回复格式跟随发送格式

一般可不使用地址码与校验码；下位机回复帧格式会与上位机发送格式保持一致（同样带/不带 `@`、`#` 等扩展）。

---

## 7. 错误信息码（`ERRORCODE`）

应答格式：`CMD:REPLY=ERRORCODE\r`

| `ERRORCODE` | 含义 |
|---------------|------|
| `0` | 设定/查询/保存：未找到子模块名或参数名 |
| `1` | 设定命令执行成功 |
| `2` | 设定/查询/保存：未找到参数名 |
| `3` | 设定/查询/保存：操作被禁止 |
| `4` | 设定：参数值超出允许范围 |
| `5` | 其它或未知错误 |
| `6` | 命令格式/语法错误 |
| `7` | 通讯帧校验错误 |
| `8` | 保存命令执行成功 |

#### 8.2.1 温度设置

**参数**：调节温度
**通讯命令**：`TC1:TCADJTEMP`
**数据类型**：`NUM`
**帮助信息**：
```
1. 通过该值设置温控目标的温度；
2. 为了防止用户在调节温度时超出允许范围，可通过“温度选项”目录里的“最低设定温度”和“最高设定温度”来限制调节范围。
```
---

**参数**：实际温度
**通讯命令**：`TC1:TCACTTEMP`
**数据类型**：`NUM`
**帮助信息**：
```
1. 温控目标的实际温度（温度传感器的测量温度）。
```
---

#### 8.2.2 温度选项

**参数**：设定温度
**通讯命令**：`TC1:TCSETTEMP`
**数据类型**：`NUM`
**帮助信息**：
```
1. “调节温度”由用户设置，用户设置到哪个值，就立即变化到哪个值。
2. “设定温度”是模块自动计算的。它被“温度限速”后向“调节温度”变化，直至和“调节温度”相同。
3. 温控器输出功率，控制温控目标的“实际温度”追踪“设定温度”。通常情况下，“实际温度”的变化速度小于或等于“温度限速”值。
```
---

**参数**：温度限速
**通讯命令**：`TC1:TCRAMPSPEED`
**数据类型**：`NUM`
**帮助信息**：
```
1. “温度限速”会限制“设定温度”的变化速度；
2. 当温控器输出关闭时，“设定温度”会自动被设置为温控目标的“实际温度”，防止下次输出开启时出现跳变；
3. 通过减小“温度限速”可以防止温控目标的温度变化过快；合理设置可以得到温度曲线效果。
```
---

**参数**：最高设定温度
**通讯命令**：`TC1:TCMAXTEMP`
**数据类型**：`NUM`
**帮助信息**：
```
1. "调节温度"允许调节的最大值，防止用户调节时超出范围，可根据需要修改。
```
---

**参数**：温度调节步进值
**通讯命令**：`TC1:TCSTEPTEMP`
**数据类型**：`NUM`
**帮助信息**：
```
1. 用户使用旋钮或者按钮增大、减小参数"调节温度"时的步进值，跟控温分辨率精度无关。
```

#### 8.2.3 输出设置及状态

**参数**：最大输出电压
**通讯命令**：`TC1:TCMAXV`
**数据类型**：`NUM`
**帮助信息**：
```
1. 为了安全，在有功率输出时，温控器会禁止调节“最大输出电压”；所以用户要先关闭温控的功率输出，然后才可以修改该参数。
2. 调节时，最大输出电压被限定在0.1V与“过压保护阈值”之间。当调节无法增大该值时，请检查“过压保护阈值”的设置值。
3. 温控器的“最大输出电压”可以通过软件设置，因此用户可以先根据自己的温控系统需要选择合适的TEC，然后再根据所选TEC设置该参数。
4. 温控器“最大输出电压”对应着最大温控功率，需要根据温控系统的极限工作条件来确定。如果设置过大，可能会造成TEC损坏或者电源功率不够；如果过小，会导致TEC功率不够，无法温控到设定温度。
5. 温控模块最大输出电压 ≧ 所需的最大温控功率对应的电压。
6. 温控模块最大输出电压 < 过压保护阈值 - 噪声容限。要注意，最大输出电压和过压保护阈值不能太接近，否则容易误报错；噪声容限一般取电源电压的3%-10%。
7. 温控模块实际输出电压 在区间[负向最大输出电压, 正向最大输出电压]范围内。实际输出电压是根据温度反馈实时PID控制的结果，其绝对值在0和最大输出电压之间。
8. 实际使用时，可以先设置一个较小值，然后实验，如果功率不够，再逐步增大。
9. 过压保护阈值 < 温控模块的电源电压*95%；过压保护阈值 < TEC最大工作电压。关于过压保护阈值的详细内容,参见过压保护阈值的帮助和用户手册。
10. 更详细的说明请参考用户手册。
```
---

**参数**：冷热电压比值
**通讯命令**：`TC1:TCCOOLVRATIO`
**数据类型**：`NUM`
**帮助信息**：
```
1. 最大制冷电压相对于最大加热电压的比值，通过该参数，可以实现加热和制冷电压不相同。
2. 如果该比值小于1，则最大加热电压等于“最大输出电压”；最大致冷电压等于该比值乘以“最大输出电压”。
3. 如果该比值大于1，则最大致冷电压等于“最大输出电压”；最大加热电压等于“最大输出电压”除以该比值。
4. 一般情况下，该值不需要修改。
```
---

**参数**：输出模式
**通讯命令**：`TC1:TCMODE`
**数据类型**：`OPT_TCMODE`
**可选值**：0 (含义: 致冷模式)
**可选值**：1 (含义: 加热模式)
**可选值**：2 (含义: 双向模式)
**帮助信息**：
```
1. 为了安全，在温控器有功率输出时，程序禁止“输出模式”被改变；所以用户要先关闭温控的功率输出，然后才可以修改该参数。
2. 致冷模式：温控器只致冷，不加热；适合情况：有内热或温控温度低于环境温度；适合TEC。
3. 加热模式：温控器只加热，不致冷。适合情况：温控温度高于环境温度；适合TEC、加热棒。
4. 双向模式：双向温控器既可以加热，也可以致冷；适合TEC。
```

**可选值**：4 (含义: 自动整定)
**可选值**：5 (含义: 从模式)
**帮助信息**：
```

8. “自动整定”是针对PID方式整定的，整定结果使用PID方式最佳；但用户也可以对整定的参数用PI或者PID类型做个比较，根据结果选择PID类型。

```

**参数**：错误掩码
**通讯命令**：`TC1:TCERRORMASK`
**数据类型**：`BINARYCODE`
**帮助信息**：
```
1. 错误掩码：用于设定不可恢复的错误。
2. 系统具有完善的监控和保护功能，能够发现错误关闭输出，同时具有输出自动恢复功能，能在错误消失后自动恢复功率输出。但是，某些错误的出现可能代表温控系统出现了一些严重问题，因此用户可以设置这些错误导致的温控器关闭不能被自动恢复功能恢复。
3. 用1个8位二进制数来记录错误掩码；每1位代表1种错误；某种错误发生后，即使故障消除也不允许恢复，则对应位为0；某种错误发生后，如果故障消除允许恢复，则对应位为1。
4. 错误掩码对应位代表的错误和错误日志对应位代表的错误一样。
    第0位：外部；
    第1位：过压；
    第2位：过流；
    第3位：过温；
    第4位：温度传感器开路；
    第5位：负载短路；
    第6位：负载开路；
    其它位：保留。
5. 比如，允许任何错误情况下，都能够自动恢复，则错误掩码是255（二进制为11111111）；如果只不允许过压和过流错误自动恢复，则错误掩码为249（二进制为11111001）。
```
