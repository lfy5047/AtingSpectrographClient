# 红外机芯客户端开发文档

本文档面向上位机/客户端开发，说明红外机芯接口拆分后的接入方式。完整 TCP 控制帧、错误码和全部命令表见 [客户端命令接口.md](./客户端命令接口.md)。

## 1. 改动摘要

红外机芯接口已经从旧版一级 `ir.*` 拆分为三个入口：

| 命名空间 | 用途 | 说明 |
|----------|------|------|
| `ir.core.current` | 查询当前机芯型号 | 返回服务启动时从 `conf.json` 读取的静态机芯型号 |
| `ir.legacy.*` | 旧红外机芯 | 旧 RS422 机芯控制协议，底层帧为 `5E 5E ... E5 E5` |
| `ir.ci05.*` | CI05 机芯 | 新 CI05 独立控制协议，底层控制帧为 `55 AA ... F0` |

旧版 `ir.*` 一级命令已经移除。客户端升级时必须把旧机芯命令迁移到 `ir.legacy.*`，CI05 机芯命令使用 `ir.ci05.*`。

## 2. 客户端接入流程

客户端建立 TCP 控制连接后，先调用 `ir.core.current`：

```json
{"cmd":"ir.core.current","params":{}}
```

响应示例：

```json
{"ok":true,"data":{"model":"ci05"}}
```

`model` 只会是：

| 值 | 客户端行为 |
|----|------------|
| `legacy` | 使用 `ir.legacy.*` 命令 |
| `ci05` | 使用 `ir.ci05.*` 命令 |

该值来自服务端启动时配置，不支持客户端运行时热切换。现场更换机芯或切换型号后，需要修改服务端配置并重启服务。

推荐客户端初始化顺序：

1. 建立 TCP 连接并调用 `system.version`，确认控制协议版本为 `2`。
2. 调用 `ir.core.current`，确定当前机芯命名空间。
3. 根据 `model` 初始化对应 UI 和命令按钮。
4. 对 CI05，建议启动后读取 `ir.ci05.read_work_state`、`ir.ci05.read_self_check`、`ir.ci05.read_status1` 到 `read_status4`，用于展示当前状态。
5. 对连续调焦/变倍类操作，在按钮释放、客户端超时、页面切换或 TCP 断开前主动发送停止命令。

## 3. 通用请求和响应

红外命令仍走 TCP 控制通道 JSON-RPC 风格请求。成功响应外层固定为：

```json
{
  "ok": true,
  "data": {}
}
```

失败响应外层固定为：

```json
{
  "ok": false,
  "code": -21,
  "msg": "ir transact failed"
}
```

客户端不要只按 TCP 收发成功判断命令成功，必须检查 `ok`。常见错误码：

| code | 含义 | 客户端处理建议 |
|------|------|----------------|
| `-1` | 未知命令 | 服务端版本过旧，或客户端仍在调用旧一级 `ir.*` |
| `-3` | 参数错误 | 检查枚举范围、必填字段和数值单位 |
| `-10` | 子系统未绑定 | 当前服务端未初始化对应机芯对象或串口配置为空 |
| `-11` | 设备未就绪 | legacy 维护操作正在执行等 |
| `-21` | 红外机芯通信失败 | 串口未打开、机芯未响应、超时或返回错误帧 |

## 4. Legacy 旧机芯接口

legacy 命令全部使用 `ir.legacy.*`。命名命令的返回已经语义化：

读命令返回：

```json
{"ok":true,"data":{"value":3}}
```

写命令返回：

```json
{"ok":true,"data":{"success":true}}
```

仅 `ir.legacy.send_raw` 保留原始透传结构：

```json
{
  "cmd": "ir.legacy.send_raw",
  "params": {
    "cmd": 32,
    "data": [],
    "readback_len": 1
  }
}
```

```json
{"ok":true,"data":{"cmd":32,"data":[1],"warning":""}}
```

迁移旧客户端时重点替换：

| 旧调用 | 新调用 |
|--------|--------|
| `ir.send_raw` | `ir.legacy.send_raw` |
| `ir.set_brightness` | `ir.legacy.set_brightness` |
| `ir.set_contrast` | `ir.legacy.set_contrast` |
| `ir.set_integration` | `ir.legacy.set_integration` |
| `ir.read_module_id` | `ir.legacy.read_module_id` |
| `ir.read_self_check` | `ir.legacy.read_self_check` |
| `ir.trigger_calibration` | `ir.legacy.trigger_calibration` |

注意：`ir.legacy.read_module_id` 当前返回 1 字节数值 ID，不再返回旧版原始 8 字节数组。需要旧 raw 行为时使用 `ir.legacy.send_raw`。

## 5. CI05 接口语义

CI05 命令全部使用 `ir.ci05.*`。CI05 底层说明书没有统一 ACK，所以服务端把 CI05 命令分为两类：

| 类型 | 服务端行为 | 客户端判断 |
|------|------------|------------|
| 写命令 | 只确认完整控制帧已写入串口 | `data.success=true` 表示写串口成功，不代表机芯状态已变化 |
| 查询命令 | 写入查询命令并等待匹配的 `55 BB` 反馈帧 | `data.value` 是解析后的状态或数值 |

写命令示例：

```json
{"cmd":"ir.ci05.set_brightness","params":{"value":50}}
```

```json
{"ok":true,"data":{"success":true}}
```

查询命令示例：

```json
{"cmd":"ir.ci05.read_status1","params":{}}
```

```json
{
  "ok": true,
  "data": {
    "value": {
      "brightness": 50,
      "contrast": 40,
      "integration_us": 1000,
      "integration_gear": 0,
      "background_gear": 0,
      "sync_mode": 0,
      "ezoom": 0
    }
  }
}
```

如果业务需要确认某个写命令是否真正生效，应在写命令后追加对应查询命令。例如设置亮度后调用 `ir.ci05.read_status1`，设置帧频后调用 `ir.ci05.read_frame_rate_hz` 或 `ir.ci05.read_status4`。

## 6. CI05 常用控制

### 6.1 镜头控制

| 功能 | 命令 | 参数 | 备注 |
|------|------|------|------|
| 连续正向调焦 | `ir.ci05.focus_start_positive` | 无 | 必须配合 `focus_stop` |
| 连续负向调焦 | `ir.ci05.focus_start_negative` | 无 | 必须配合 `focus_stop` |
| 停止调焦 | `ir.ci05.focus_stop` | 无 | 可重复调用 |
| 单步正向调焦 | `ir.ci05.focus_step_positive` | 无 | 单次动作 |
| 单步负向调焦 | `ir.ci05.focus_step_negative` | 无 | 单次动作 |
| 连续正向变倍 | `ir.ci05.zoom_start_positive` | 无 | 必须配合 `zoom_stop` |
| 连续负向变倍 | `ir.ci05.zoom_start_negative` | 无 | 必须配合 `zoom_stop` |
| 停止变倍 | `ir.ci05.zoom_stop` | 无 | 可重复调用 |
| 自动聚焦 | `ir.ci05.auto_focus` | 无 | 可能耗时较长 |
| 设置视场 | `ir.ci05.set_fov` | `value` 0~2 | 0=宽视场，1=中视场，2=窄视场 |
| 设置调焦速度 | `ir.ci05.set_focus_speed` | `value` 0~10 | 写命令 |
| 设置变倍速度 | `ir.ci05.set_zoom_speed` | `value` 0~10 | 写命令 |
| 查询焦距 | `ir.ci05.query_focal_length` | 无 | 返回焦距、镜头供电和主通道 |
| 查询调焦电机位置 | `ir.ci05.query_focus_motor_position` | 无 | 返回 `uint32` |
| 查询变倍电机位置 | `ir.ci05.query_zoom_motor_position` | 无 | 返回 `uint32` |

连续控制建议实现为按下发送 `start`、松开发送 `stop`。客户端异常退出前尽量补发 `focus_stop` 和 `zoom_stop`。

### 6.2 图像参数

| 功能 | 命令 | 参数 |
|------|------|------|
| 亮度 | `ir.ci05.set_brightness` | `value` 0~100 |
| 对比度 | `ir.ci05.set_contrast` | `value` 0~100 |
| 全局亮度 | `ir.ci05.set_overall_brightness` | `value` 0~100 |
| 全局对比度 | `ir.ci05.set_overall_contrast` | `value` 0~100 |
| 锐化 | `ir.ci05.set_sharpness` | `value` 0~7 |
| 电子放大 | `ir.ci05.set_ezoom` | `value` 0~2，0=1X，1=2X，2=4X |
| 图像冻结 | `ir.ci05.set_freeze` | `value` 0/1 |
| 镜像模式 | `ir.ci05.set_mirror_mode` | `value` 0~3 |
| 极性/伪彩 | `ir.ci05.set_polarity_palette` | `value` 0~7 |
| AGC 模式 | `ir.ci05.set_agc_mode` | `value` 0/1 |
| 保存参数 | `ir.ci05.save_params` | 无 |

### 6.3 积分、帧频和补偿

| 功能 | 命令 | 参数 | 单位 |
|------|------|------|------|
| 设置积分时间 | `ir.ci05.set_integration_ms_x10` | `value` uint16 | 0.1 ms |
| 设置 CLK 积分时间 | `ir.ci05.set_integration_mc` | `value` 0~16777215 | CLK |
| 设置帧频 | `ir.ci05.set_frame_rate_hz_x100` | `value` uint16 | 0.01 Hz，即 `value = Hz × 100` |
| 读取帧频 | `ir.ci05.read_frame_rate_hz` | 无 | Hz，无缩放 |
| 设置积分档位 | `ir.ci05.set_integration_gear` | `value` 0~2 | 枚举 |
| 设置积分档位自动 | `ir.ci05.set_integration_gear_auto` | `value` 0/1 | 枚举 |
| 设置本底档位 | `ir.ci05.set_background_gear` | `value` 0~2 | 枚举 |
| 设置本底档位自动 | `ir.ci05.set_background_gear_auto` | `value` 0/1 | 枚举 |
| 快门补偿 | `ir.ci05.trigger_shutter_compensation` | 无 | 动作 |
| 场景补偿 | `ir.ci05.trigger_scene_compensation` | 无 | 需要均匀场景 |
| 离焦补偿 | `ir.ci05.trigger_defocus_compensation` | 无 | 动作 |
| 积分时间校正 | `ir.ci05.trigger_integration_correction` | 无 | 动作 |

注意帧频单位不对称：设置命令的 `value` 使用 0.01 Hz 编码单位，即 `value = Hz × 100`；读取命令返回原始 Hz。客户端显示和保存配置时不要把读取值再除以 100。

### 6.4 状态读取

| 命令 | 返回 `data.value` |
|------|-------------------|
| `ir.ci05.read_serial_number` | `uint8[]`，当前保留原始 5 字节 |
| `ir.ci05.read_work_minutes` | `uint32`，累计工作分钟 |
| `ir.ci05.read_cooling_done_seconds` | `uint16`，本次制冷完成时间，单位秒 |
| `ir.ci05.read_status1` | 亮度、对比度、积分、档位、同步模式、电子放大 |
| `ir.ci05.read_status2` | 锐化、参数行、滤波、镜像、极性/伪彩、视频源、图像模式、测试图 |
| `ir.ci05.read_status3` | 探测器供电、光标显示、坏元光标坐标、焦平面温度 |
| `ir.ci05.read_status4` | `frame_rate_hz` |
| `ir.ci05.read_frame_rate_hz` | `uint8`，帧频 Hz |
| `ir.ci05.read_work_state` | `realtime`、`cooling`、`raw` |
| `ir.ci05.read_self_check` | `success`、`raw` |

`read_status3` 中 `focus_plane_temp_x10` 的单位是 0.1 摄氏度，客户端显示摄氏度时需要除以 10。

## 7. CI05 原始透传

`ir.ci05.send_raw` 用于调试或厂商命令兜底。普通业务优先使用命名命令。

请求字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `data1` | uint8 | CI05 控制帧 DATA1 |
| `data2` | uint8 | CI05 控制帧 DATA2 |
| `data3` | uint8 | CI05 控制帧 DATA3 |
| `data4` | uint8 | CI05 控制帧 DATA4 |
| `expected_type` | uint8 | 期望反馈帧类型 |
| `timeout_ms` | int | 1~10000 |

示例：

```json
{
  "cmd": "ir.ci05.send_raw",
  "params": {
    "data1": 0,
    "data2": 1,
    "data3": 32,
    "data4": 0,
    "expected_type": 32,
    "timeout_ms": 100
  }
}
```

成功响应：

```json
{"ok":true,"data":{"type":32,"data":[1,1,134,0,0]}}
```

服务端会等待匹配 `expected_type` 的反馈帧，并跳过不相关的异步/状态反馈。

## 8. 危险命令边界

以下 CI05 命令会改变机芯内部状态、持久化参数、坏元列表或探测器供电状态，不应放入普通自动流程：

| 类别 | 命令 |
|------|------|
| 串口透传 | `ir.ci05.serial_passthrough_enable` |
| NUC | `ir.ci05.nuc_collect_cl`、`ir.ci05.nuc_collect_ch_calc_k`、`ir.ci05.nuc_save_b`、`ir.ci05.nuc_load_b`、`ir.ci05.nuc_save_k`、`ir.ci05.nuc_load_k`、`ir.ci05.nuc_clear_b`、`ir.ci05.nuc_clear_k` |
| 坏元表 | `ir.ci05.bad_pixel_add_current`、`ir.ci05.bad_pixel_clear_current`、`ir.ci05.bad_pixel_auto_find_start`、`ir.ci05.bad_pixel_save_list`、`ir.ci05.bad_pixel_load_list`、`ir.ci05.bad_pixel_clear_list` |
| 探测器供电 | `ir.ci05.set_detector_power` |

建议客户端只在工程师维护模式中开放这些命令，并增加二次确认、操作日志和权限控制。

## 9. 推荐客户端实现要点

- 以 `ir.core.current` 结果决定 UI 命令集，不要同时向两个命名空间发送同类业务命令。
- 不再调用旧一级 `ir.*` 命令；旧服务端和新服务端的红外返回结构不同，客户端应按部署版本适配。
- 所有参数字段都显式传入；不要依赖服务端补默认值。
- 对 CI05 写命令，`success=true` 只代表串口写成功；需要闭环时追加查询命令。
- 对连续运动类命令，客户端必须维护“已开始但未停止”的状态，并在异常路径补发停止命令。
- 对慢命令或补偿命令，客户端 UI 应显示忙状态，避免同一 TCP 连接上继续堆叠控制操作。
- 对 `-21`，优先提示检查机芯串口、供电、机芯型号配置和是否有异步状态帧干扰；不要把它当作参数错误。

## 10. 最小联调清单

Legacy 现场：

```json
{"cmd":"ir.core.current","params":{}}
{"cmd":"ir.legacy.get_version","params":{}}
{"cmd":"ir.legacy.read_self_check","params":{}}
{"cmd":"ir.legacy.set_brightness","params":{"value":128}}
```

CI05 现场：

```json
{"cmd":"ir.core.current","params":{}}
{"cmd":"ir.ci05.read_work_state","params":{}}
{"cmd":"ir.ci05.read_self_check","params":{}}
{"cmd":"ir.ci05.read_status1","params":{}}
{"cmd":"ir.ci05.set_brightness","params":{"value":50}}
{"cmd":"ir.ci05.read_status1","params":{}}
{"cmd":"ir.ci05.focus_step_positive","params":{}}
```

验收标准：

- `ir.core.current` 返回值与现场配置一致。
- 当前机芯命名空间下的读命令能返回 `ok=true`。
- 参数越界时返回 `code=-3`，客户端能展示参数错误。
- 串口断开或机芯未响应时返回 `code=-21` 或 `code=-10`，客户端能展示设备/通信异常。
- CI05 连续调焦/变倍按钮释放后必须能发送对应停止命令。
