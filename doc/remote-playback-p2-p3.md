# 远程回放 P2/P3 改进说明

本文记录客户端远程回放面板在 P2/P3 阶段的主要行为、交互约定和维护注意事项。相关实现集中在 `RecordPlaybackPanel` 与 `RemoteFileDownloader`。

## 已实现能力

- TIF 渲染改为后台线程执行，UI 线程不直接读取和合成大 TIF。
- TIF 渲染请求采用最新请求优先策略，连续切帧或修改参数时会取消旧请求，避免旧结果覆盖当前画面。
- 播放进入 TIF 帧时暂停计时，渲染完成并显示后再进入下一拍，保证帧顺序稳定。
- raw 帧仍同步显示，播放状态由 `playbackRequested_` 表示用户意图，避免 TIF 渲染回调在用户暂停后重新启动播放。
- TIF 参数区只在当前帧为 TIF 时显示；当前帧为 raw 时隐藏整个参数区。
- TIF 参数区按渲染模式显示对应控件：
  - 单波段：显示单波段选择。
  - 范围平均：显示起始波段、结束波段和“到最后一页”。
  - 单波段 RGB 合成：显示 R/G/B Band。
  - 范围平均 RGB 合成：显示 R/G/B begin/end 和各通道独立“到最后一页”。
- 波段控件使用 Slider + SpinBox 双向同步，UI 使用 1-based 显示，内部转换为 0-based 范围。
- 进度条支持拖动和点击跳转，播放中跳转会在跳转完成后按原播放意图继续。
- “停止”调整为“回到开头”，会暂停播放、跳到首帧并清零坏帧跳过计数。
- 坏帧策略支持“暂停并提示”和“跳过坏帧继续播放”。
- 下载失败原因改为结构化枚举，用户取消不会触发自动重试，网络/协议/文件写入类错误最多自动重试一次。
- 本地缓存增加 `manifest.json`，兼容无清单旧缓存，并区分未下载、不完整、已缓存、已缓存（无清单）、可能过期。
- 缓存清理前会先取消相关 TIF 渲染；取消超时则放弃清理，避免 Windows 文件句柄占用导致删除失败。
- 播放序列支持替换、追加、移除选中和清空；追加时按 `(type, record_id)` 去重。
- 播放序列选中行后可立即点击“移除选中”；移除正在渲染的 TIF 记录前会先取消渲染。
- 记录表支持双击或右键查看详情，可查看 record_id、类型、时间、文件列表、缓存状态和缓存路径。

## 关键交互约定

- “下载并播放”会替换当前播放序列。
- “下载并追加”会追加到当前播放序列，已存在记录会跳过并提示。
- TIF 渲染参数变化走 debounce；播放 tick、上一帧、下一帧、进度条和帧号跳转立即提交渲染。
- 用户点击“暂停”后，即使当前正在等待 TIF 渲染完成，也不会自动恢复播放。
- 当前帧是 raw 时不展示 TIF 渲染参数，减少误操作和视觉噪声。
- 清理全部缓存前如果当前播放序列依赖缓存，会提示用户确认；渲染取消失败时不清空序列、不删除文件。

## 维护注意事项

- `RemoteFileDownloader::failed` 信号携带 `RemoteDownloadErrorReason`，新增调用点时不要再解析错误字符串判断失败类型。
- `manifest.json` 只用文件名和大小判断是否可能过期；record timestamp 仅用于展示，不作为过期依据。
- TIF worker 返回结果时必须校验 `requestId` 和目标帧，过期结果应丢弃。
- 修改播放恢复逻辑时同时检查 raw 同步路径和 TIF 异步回调路径，避免暂停后被回调重新启动。
- 修改 TIF 参数 UI 时应通过表单行容器隐藏整行，不要只隐藏 Slider 或 SpinBox，否则标签会残留。

## 验证

构建验证在仓库根目录运行：

```powershell
.\make.bat
```

重点手工验证：

- raw 播放时 TIF 参数区隐藏，TIF 帧显示参数区。
- 切换四种 TIF 渲染模式时，只显示对应参数行。
- 播放过程中点击暂停或按空格，播放不会在 TIF 渲染完成后自动恢复。
- 播放序列展开后选中记录，“移除选中”按钮可用并能移除记录。
- 下载取消、失败重试、缓存状态刷新和清理缓存仍可用。
